🧘 집중, 🎬 극적, ☀️ 경쾌, ⚡ 활기, 🎵 로파이 — 발표 분위기에 맞는 음악을 골라보세요. 타이머와 연동되어 자동 재생·정지됩니다.

Chrome 오버레이

발표 슬라이드 위에 바로 띄우는 오버레이 위젯. Shadow DOM으로 페이지 스타일과 완전히 분리됩니다.

항상 최상단 고정

Electron 앱에서 Always-on-top 토글로 발표 중 다른 창 위에 항상 타이머를 유지합니다. 트레이에서 간편 제어.

알림음 & 종료음

10초 전 틱 알림과 타이머 종료 효과음. Web Audio API 합성으로 별도 파일 없이 즉시 동작합니다.

멀티 테마

Dark · Breeze · Ocean · Sunset — 4가지 컬러 테마를 지원합니다. 취향에 맞게 골라 사용하세요.

설치 방법

어떤 환경에서나

1

설치 파일 다운로드

아래 다운로드 버튼을 눌러 FlowTimer Setup.exe를 받습니다.

2

설치 실행

다운로드한 파일을 실행하고 설치 마법사를 따라 진행합니다.
Windows Defender 경고가 뜨면 "추가 정보 → 실행"을 클릭하세요.

3

실행

바탕화면 아이콘 또는 시작 메뉴에서 FlowTimer를 실행합니다. 트레이 아이콘으로 언제든 접근할 수 있습니다.

1

개발자 모드 활성화

Chrome에서 chrome://extensions으로 이동 후 우측 상단 개발자 모드를 켭니다.

2

소스 다운로드

GitHub에서 소스를 ZIP으로 다운로드하거나 git clone합니다.

3

확장 로드

"압축 해제된 확장 프로그램 로드"를 클릭 후 다운로드한 FlowTimer 루트 폴더를 선택합니다.

4

사용

툴바의 FlowTimer 아이콘을 클릭해 팝업 타이머를 열거나, 아무 페이지에서나 오버레이 위젯을 사용합니다.
